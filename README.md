Maven Market Power BI Dashboard

📊 Project Overview


This project presents an interactive Maven Market Sales Dashboard created using Microsoft Power BI. The dashboard analyzes sales performance, revenue, profitability, transactions, return rates, brands, cities, and store locations.

📌 Key KPIs

Total Transactions: 6K

Total Revenue: $42.7K

Profit Margin: 60.60%

Return Rate: 0.84%

🔍 Key Insights

Seattle is a high-volume and high-revenue market with approximately 1,010 transactions and around $4.0K revenue.

Portland generated approximately 350+ transactions and around $2.9K revenue with a low return rate.

Beverly Hills is a more profitability-focused and premium market, with a profit margin of approximately 55%.

The overall business achieved a strong 60.60% profit margin.

The overall return rate remained low at 0.84%, indicating good product performance and customer satisfaction.


Hermanos recorded the highest number of transactions among the listed brands.
Salem generated the highest revenue among the top-performing cities.

Revenue showed stronger performance during 2024, with noticeable growth toward the end of the year.

The dashboard provides a clear comparison of actual performance versus targets for revenue, profit, and returns.
